# Introduction

- **Security Risks Are Pervasive**: There are many types of security risks to consider.
- **Attackers Aim for Access**: We need ways to prevent them from gaining unauthorized access.
- **Assets Include Diverse Items**:
    - Data
    - Physical Property (buildings, equipment)
    - Computer Systems
    - People
    - Everything in the Organization

**Purpose of Security Controls**:
- Prevent security events from occurring.
- Minimize the impact if an event happens.
- Limit damage if someone gains unauthorized access.

## Control Categories

These are broad classifications of where controls are implemented.

### Technical Controls
- **Definition**: Controls implemented using systems or technology.
- **Examples**:
    - Operating System Controls (e.g., user permissions, password policies enforced by the OS)
    - Firewalls (blocking network traffic)
    - Antivirus Software (detecting and removing malware)

### Managerial Controls
- **Definition**: Administrative controls associated with security design and implementation, often set by management.
- **Examples**:
    - Security Policies (written rules and guidelines)
    - Standard Operating Procedures (SOPs) (step-by-step instructions for tasks)
    - Risk Assessments, Security Audits

### Operational Controls
- **Definition**: Controls implemented by people, rather than systems. These are day-to-day practices.
- **Examples**:
    - Security Guards (human presence for monitoring and response)
    - Awareness Programs (training employees on security best practices)
    - Incident Response Procedures (actions taken during a security event)

### Physical Controls
- **Definition**: Controls that limit physical access to assets.
- **Examples**:
    - Guard Shack Checks (all identification)
    - Fences, Locks (physical barriers)
    - Badge Readers (restricting access to certain areas)
    - Surveillance Cameras

### Preventive Control Types
- **Purpose**: Blocks access to a resource or prevents a security event from occurring.
- **Function**: Actively stops an unwanted action.

### Deterrent Control Types
- **Purpose**: Discourages an intrusion attempt; makes an attacker think twice.
- **Function**: Influences behavior to avoid an attack.

### Detective Control Types
- **Purpose**: Identifies and logs an intrusion attempt. Helps find the issue after it occurs.
- **Function**: Discovers and records security events.

### Corrective Control Types
- **Purpose**: Applied after an event has been detected to reverse the impact or continue operating with minimal downtime.
- **Function**: Mitigates damage, restores systems, manages consequences.

### Compensating Control Types
- **Purpose**: Provides an alternative means of control when existing controls aren't sufficient or cannot be implemented. May be temporary.
- **Function**: Addresses a security gap with an alternative solution.

### Directive Control Types
- **Purpose**: Directs a subject towards security compliance.
- **Function**: Guides individuals to follow security procedures or policies.

## Managing Security Controls

- **Not Exclusive Lists**: The examples provided are not exhaustive, and there are many more controls.
- **Combination of Types**: Organizations often combine different control categories and types.
- **Overlap**: Some security controls may exist in multiple types or categories (e.g., a security guard performing ID checks).
- **Evolution**: New security controls are constantly created as systems, processes, and threats evolve.
- **Tailored Solutions**: Different organizations will utilize different security controls based on their specific needs, risks, and resources.

## Takeaways for Exam

1. **Understand the Core Purpose of Controls**:
    - Prevent: Stop security events from occurring.
    - Minimize Impact: Reduce the damage if an event happens.
    - Limit Damage: Contain the effects if someone gains unauthorized access.

2. **Differentiate Control Categories**:
    - **Technical**: Systems/Software
    - **Managerial**: Management/Policies
    - **Operational**: People/Processes
    - **Physical**: Physical Barriers/Access Control

3. **Differentiate Control Types**:
    - **Preventive**: Stops it before it happens.
    - **Deterrent**: Makes attackers think twice.
    - **Detective**: Identifies it after it happens.
    - **Corrective**: Fixes it after it happens.
    - **Compensating**: Provides an alternative control when primary isn't feasible.
    - **Directive**: Guides behavior (weakest, relies on compliance).

4. **Practice Categorization and Typing**:
    - **Example**: A `firewall` is a `Technical` control with a `Preventive` function (blocking unwanted traffic).
    - **Example**: `Security Awareness Training` is an `Operational` control with a `Directive` function (guiding users to be more secure).

5. **Recognize Overlap**:
    - A single control might have elements of multiple types or categories.
    - Example: A security guard checking IDs at a gate acts as both Preventive and Deterrent.

6. **Context Matters**:
    - The effectiveness and classification of a control can depend on the specific context and nature of threats.

7. **Security is Dynamic**:
    - Controls are not static; they evolve with technology, threats, and organizational needs.
    - New controls are always being developed.
