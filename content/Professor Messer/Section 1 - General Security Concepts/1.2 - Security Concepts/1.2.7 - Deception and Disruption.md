# Deception and Disruption in Information Security

## Introduction
- As an IT security professional, preventing attackers is crucial. However, security knowledge and techniques can also be used to create **deception** and **disruption** against them.

## Honeypots
### Definition
- A system designed to attract malicious actors and trap them there.
### Purpose
- **Observe Security Techniques**: Understand the methods attackers use.
- **Reconnaissance**: Study attacker behaviors and tactics.
- **Waste Resources**: Keep attackers engaged, wasting their time and resources.

### Nature
- Often, an "attacker" is an automated machine (bot) scanning for vulnerabilities.
- Honeypots create a virtual environment to explore.
- They are not part of production processes; they serve as decoys.

### Implementation
- Many open-source and commercial options are available.
- The challenge lies in making honeypots realistic enough to fool attackers. As attackers improve, administrators must enhance their complexity and sophistication.

## Honeynets
### Definition
- A larger, more complex deception network using one or more honeypots and other virtualized network components.
### Components
- Servers
- Workstations
- Routers
- Switches
- Firewalls
- Other devices to mimic a real network infrastructure

### Purpose
- Create a more believable environment for attackers.
- Keep them engaged longer, gathering comprehensive intelligence.

### Example/Resource
- **Project Honey Pot**: Used to stop spammers and gather intelligence.

## Honeyfiles
### Definition
- Files containing fake information designed to attract attackers.
### Purpose
- Act as bait within honeypots or production networks.
- Designed to appear valuable to an attacker.

### Examples
- A file named `passwords.txt` that does not contain actual passwords.

### Detection
- An alert is sent if the honeyfile is accessed, opened, or viewed.
- Acts as a virtual bear trap for unauthorized probing.

## Honeytokens
### Definition
- Traceable data added to honeypots (or production systems) to track malicious actors.
### Purpose
- Identify attackers after they steal or leak data.
- Help trace the attacker's path and subsequent actions.

### Examples
- **Fake API Credentials**: Do not provide access but send notifications when used.
- **Fake Email Addresses**: Added to a contact list for monitoring public appearances.
- **Other Examples**: Falsified database records, unique browser cookies, web page pixels designed for tracking usage.

## Exam Takeaways: Deception and Disruption
### Overall Concept
- Advanced cybersecurity strategies that mislead attackers, waste their resources, and gather intelligence on their methods.

### Key Technologies for Deception

#### 1. Honeypots
- **What it is**: A single, isolated virtual system (e.g., a server or workstation) designed to look like a real target but is actually a decoy.
- **Purpose**:
    - Attract attackers and divert them from real production systems.
    - Trap attackers and keep them engaged.
    - Gather intelligence on attacker tools, techniques, and procedures (TTPs).
    - Monitor automated scans.

#### 2. Honeynets
- **What it is**: A network of multiple interconnected honeypots and virtualized devices simulating a larger, more complex real network infrastructure.
- **Purpose**:
    - Create a more believable deception environment.
    - Engage more sophisticated attackers for longer periods.
    - Gather broader intelligence on how attackers navigate and escalate privileges within a network.

#### 3. Honeyfiles
- **What it is**: Individual files containing fake, tempting information placed within a honeypot or honeynet.
- **Purpose**:
    - Act as specific bait for attackers who have gained initial access and are searching for valuable data.
    - Trigger immediate alerts when accessed, opened, or copied.

#### 4. Honeytokens
- **What it is**: Traceable pieces of fake data or credentials embedded within a honeypot, honeynet, or even legitimate systems.
- **Purpose**:
    - Track malicious actors after they have stolen or exfiltrated data.
    - Identify the source if the fake data appears elsewhere (e.g., on public forums).

### Important Distinctions for the Exam
- **Honeypot vs. Honeynet**: A honeypot is a single decoy system, while a honeynet is a collection of honeypots and other virtual devices forming a fake network.
- **Honeyfile vs. Honeytoken**: A honeyfile is designed to be accessed, triggering an alert upon access. A honeytoken is traceable data (which might be in a file or other forms) designed to alert upon use or distribution outside the controlled environment.

### Overall Benefits of Deception Technologies
- **Attacker Diversion**: Keeps attackers busy and away from real assets.
- **Intelligence Gathering**: Provides valuable insight into attacker methods, tools, and motives.
- **Early Warning**: Can alert security teams to a breach or reconnaissance activity.
- **Resource Wastage**: Forces attackers to expend time and effort on worthless targets.
