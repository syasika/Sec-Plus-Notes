# Wireless Security Settings

## Securing a Wireless Network

### Core Concerns
- **Vulnerability to Eavesdropping:** Wireless data is sent over the air, making it susceptible to interception.
- **Protection of Confidential Information:** Data must be protected from unauthorized reading.
- **Restricting Access:** Only authorized users should have access.

### Key Security Goals
1. **User Authentication:** Verify user identity before granting access.
    - **Methods:** Username, password, Multi-Factor Authentication (MFA).
2. **Confidentiality:** Prevent unauthorized reading of data.
    - **Method:** **Encryption** to ensure wireless data is unreadable by unauthorized users.
3. **Data Integrity Verification:** Ensure that the integrity of data remains intact during transmission.
    - **Method:** **Message Integrity Check (MIC)** – ensures received data matches sent data.

## The WPA2 PSK Problem

- **WPA2 (Wi-Fi Protected Access 2):** Long-used encryption protocol for wireless networks.
- **PSK Brute-Force Vulnerability:**
    - **Mechanism:** During the initial handshake, a hash of the PSK is transmitted.
    - **Attack Process:**
        - Listen to and capture the handshake or derive the PSK hash without the full handshake.
        - Perform a **brute-force attack** on the captured hash.
    - **Why it's Easier Now:**
        - Weak PSKs are easier to guess due to weak passwords.
        - Improved GPU processing speeds make brute-forcing faster.
        - Cloud-based password cracking services offer immense computational power.
    - **Consequence:** Once the PSK is known, an attacker can access all wireless keys on that network. This lack of **Forward Secrecy** means past and future communications are compromised.

## WPA3 and GCMP

- **WPA3 (Wi-Fi Protected Access 3):** Introduced in 2018 to address WPA2 vulnerabilities.
- **GCMP (Galois/Counter Mode Protocol) Block Cipher Mode:**
    - A stronger encryption standard than WPA2.
    - Provides two main security services:
        - **Data Confidentiality:** Achieved with **AES** (Advanced Encryption Standard).
        - **Message Integrity Check (MIC):** Achieved with **GMAC** (Galois Message Authentication Code).

## SAE (Simultaneous Authentication of Equals)

- **WPA3 Changes the PSK Authentication Process:**
    - Includes mutual authentication between client and access point.
    - Creates a shared session key without transmitting that key or a brute-forcible hash across the network.
    - This eliminates 4-way handshakes that expose hashes, thus preventing brute-force attacks against the PSK.
- **SAE (Simultaneous Authentication of Equals):**
    - A **Diffie-Hellman derived key exchange** with an authentication component.
    - Each client uses a different session key even if they share the same PSK. This provides **forward secrecy**.

## Wireless Authentication Methods

### Purpose
To gain access to a wireless network (for mobile or temporary users).

### Primary Credential Types
1. **Shared Password / Pre-Shared Key (PSK):**
    - Simple, common for home networks.
    - Insecure for enterprises due to one key for all users.
2. **802.1X Centralized Authentication:**
    - Enterprise standard with individual user credentials.
    - Provides Port-based Network Access Control (NAC) – no access until authenticated.

## AAA Framework

### Fundamental Security Concept
- Understand the three components:
    - **Identification:** Who you claim to be (username).
    - **Authentication:** Proving identity (password, MFA).
    - **Authorization:** What you can do (access rights).
    - **Accounting:** Tracking actions (logs).

### Common Protocols/Servers
- **RADIUS (Remote Authentication Dial-in User Service):** A central AAA protocol used for various purposes.
- **LDAP (Lightweight Directory Access Protocol)**
- **TACACS+ (Terminal Access Controller Access Control System Plus)**

## EAP (Extensible Authentication Protocol)

### An Authentication Framework Used Within 802.1X
- Provides flexibility for different authentication methods.
- **Key Players:**
    - **Supplicant:** The client device trying to connect.
    - **Authenticator:** The device providing access (e.g., wireless access point, network switch).
    - **Authentication Server:** Validates the client credentials.

### Authentication Flow

1. **Initialization:** Supplicant attempts to connect to Authenticator (no communication yet).
2. **EAP-Request:** Authenticator sends an EAP-Request ("Anyone new?") to the Supplicant.
3. **EAP-Response (Identity):** Supplicant sends its identity (e.g., username) to the Authenticator.
4. **Forward Identity:** Authenticator forwards the identity to the Authentication Server.
5. **Auth Server OK:** Authentication Server responds, indicating readiness to proceed.
6. **EAP-Request (Credentials):** Authenticator asks for specific credentials from the Supplicant.
7. **EAP-Response (Credentials):** Supplicant sends its credentials to the Authenticator.
8. **Forward Credentials:** Authenticator forwards the credentials to the Authentication Server.
9. **Validation & Approval:** Authentication Server validates and approves or denies access.
10. **Access Granted:** Authenticator allows full network access.

# Takeaways for Exam

## Wireless Security Fundamentals (Crucial!)

- **Confidentiality, Integrity, Authentication (CIA Triad):**
    - Understand why each is important for wireless networks and how they are achieved (encryption, MIC, authentication protocols).
    - Wireless networks are inherently less secure than wired due to their broadcast nature.

## WPA2 vs. WPA3 (High Probability Exam Question!)

- **WPA2 PSK Weakness:**
    - Describe the brute-force attack against the PSK hash captured during the 4-way handshake.
    - Mention GPU processing and cloud cracking accelerating these attacks.
    - Highlight the lack of forward secrecy as a major flaw (compromised PSK means all traffic is readable).
- **WPA3 Improvements:**
    - **GCMP:** Stronger encryption (AES) and integrity (GMAC).
    - **SAE (Dragonfly Handshake):** Replaces vulnerable 4-way handshake.
        - Key benefit: Creates a unique, shared session key without transmitting the PSK hash.
        - Provides mutual authentication and forward secrecy.

## Authentication Methods

- **PSK:** Simple for home networks but insecure in enterprises.
    - One key for all users.
- **802.1X (Centralized Authentication):** Enterprise standard with individual user credentials.
    - Port-based Network Access Control (NAC) – no access until authenticated.
    - Applies to both wireless and wired networks.

## AAA Framework

- Understand the three components:
    - Identification: Who you claim to be (username).
    - Authentication: Proving identity (password, MFA).
    - Authorization: What you can do (access rights).
    - Accounting: Tracking actions (logs).

- Common protocols/servers include RADIUS, LDAP, and TACACS+.

## RADIUS

- Full name: **Remote Authentication Dial-in User Service**.
- Understand its role as a central AAA protocol.
- Used for more than just dial-in (e.g., 802.1X, VPN, network device management).

## EAP (Extensible Authentication Protocol)

- An authentication framework used within 802.1X.
- Provides flexibility for different authentication methods.
- Key players in the EAP/802.1X process include Supplicant, Authenticator, and Authentication Server.

The entire process happens quickly, often unnoticed by users.
