# Scripting and Automation

## Introduction to Scripting and Automation

**Definition:** Scripting allows for the automation and orchestration of functions that would normally be performed manually. 

### Key Advantages:
- **You Don't Have to Be There:** Scripts can resolve problems without human presence, such as during the night.
- **Proactive Problem-Solving:** Monitor and address issues before they become noticeable.
- **Speed:** Scripts run at computer system speeds, eliminating delays from human typing or misspellings. Once tested, there's no room for human error.
- **Automate Mundane Tasks:** Free up staff for more creative and interesting work.

## Automation Benefits

### Save Time:
- Eliminate the need for manual typing.
- Run scripts multiple times without human intervention.

### Enforce Baselines:
- Automatically identify and install missing security patches.
- Ensure consistent security across all systems.
- Standardize infrastructure configurations, such as router settings, firewall rules, IP addresses, and security protocols.

### Secure Scaling:
- Efficiently orchestrate cloud resources.
- Quickly scale applications and infrastructure (servers, databases) up or down.
- Ensure proper security measures, like firewalls, scale with the resources.

### Employee Retention:
- Automate repetitive tasks to ease IT staff workload.
- Minimize mundane tasks so employees can focus on more rewarding work.

### Reaction Time:
- Computers react much faster than humans.
- Address events immediately without needing a "wake-up call."
- Example: Monitoring disk space and automatically clearing temporary files before a critical outage.

### Workforce Multiplier:
- Scripts run 24/7, effectively multiplying the output of skilled personnel.
- Allow for more focused work on higher-value tasks.

## Cases for Automation

### User and Resource Provisioning
- **On-boarding and Off-boarding:** Automatically create user accounts, assign home directories, printer access, email, and group memberships for new employees. Similarly, revoke these privileges when an employee leaves.
- Assign appropriate access to resources based on roles.

### Guard Rails
- A set of automated validations to limit behaviors and responses.
- Constantly check for proper policy implementation.
- Prevent actions that could cause problems, such as blocking the deletion of critical server files.

### Security Groups
- Automate assigning (or removing) users from security groups.
- Perform continuous audits without human intervention, like alerting if someone is added to the "Administrators" group.

### Ticket Creation
- Automatically identify issues and create helpdesk tickets.
- Scripts can process email submissions, convert them into tickets, and even assign them based on content.

### Escalation
- Correct issues automatically before involving a human.
- If a script cannot resolve an issue, it can escalate the problem to the on-call technician.

### Controlling Services and Access
- Automatically enable and disable services based on schedule or triggers.
- Ensure that services are not left running unnecessarily, reducing potential attack surfaces.

### Continuous Integration and Testing (CI/CD)
- Essential for constant development and code updates in software projects.
- Scripts can securely test and deploy new code versions automatically.

### Integrations and Application Programming Interfaces (APIs)
- Scripts can interact directly with third-party devices and services via APIs.
- Eliminate manual login and clicks by "talking their language."

## Scripting Considerations

### Complexity
- Automation often involves many interacting systems, requiring extensive testing and debugging to ensure reliable operation.

### Cost
- Significant financial investment in script creation (developer time, expertise).
- Cost of implementing and integrating automation into existing infrastructure.

### Single Point of Failure
- A critical script can become a single point of failure.
- If the script stops working, it could cause significant issues or outages for dependent systems.
- Requires robust monitoring and redundancy to ensure reliability.

### Technical Debt
- Patching problems with scripts instead of fixing underlying root causes.
- This approach "pushes the issue down the road," making it more expensive and complex to address later.
- Always aim to fix the root cause, not just the symptoms.

### Ongoing Supportability
- Scripts require continuous maintenance and updates.
- Changes in operating systems, scripting languages, or integrated services can break existing scripts.
- Needs a dedicated support plan for long-term functionality and relevance.

# Exam Takeaways: Scripting and Automation

## Core Concepts & Purpose
**Definition:** Scripting automates tasks to replace manual human intervention. 
**Primary Goals:** Increase efficiency, consistency, speed, and reliability in IT operations.

## Key Benefits of Automation
1. **Time Savings & Efficiency**
   - Eliminate repetitive manual tasks.
   - Run 24/7 without human presence (solve problems even when you're sleeping).
   - Execute faster than human input (no typing/delays).

2. **Consistency & Error Reduction**
   - Ensure tasks are performed identically every time.
   - Eliminate human errors, like misspellings or forgotten steps.
   - Crucial for enforcing consistent security configurations and infrastructure builds.

3. **Proactive Problem Solving & Faster Reaction**
   - Monitor systems to identify and resolve issues before they occur or escalate.
   - Respond immediately to events, such as low disk space.

4. **Scalability & Security**
   - Enable secure scaling of cloud resources up and down.
   - Ensure security configurations are consistently applied during scaling.

5. **Improved Employee Morale/Productivity**
   - Automate mundane tasks, freeing staff for more creative and strategic work (workforce multiplier).

## Practical Use Cases
- **User Management:** On-boarding and off-boarding (account creation, access assignment/revocation).
- **Security & Compliance:** Enforcing baselines, guard rails, security group management.
- **Operations & Incident Management:** Ticket creation, escalation, service control.
- **Development & Integration:** Continuous Integration/Continuous Deployment (CI/CD), API integrations.

## Scripting Considerations
1. **Complexity**: Scripts can involve many interacting components, requiring careful design and thorough testing.
2. **Cost**: Initial investment in development time and expertise; cost of implementation and integration.
3. **Single Point of Failure**: A critical automation script can become a single point of failure for dependent systems. Requires redundancy and monitoring.
4. **Technical Debt**: Automating symptoms rather than root causes, leading to more expensive and complex fixes later.
5. **Ongoing Supportability**: Scripts need continuous maintenance, updates, and adaptation due to changes in OS, languages, or integrated services. Needs dedicated resources for long-term support.
