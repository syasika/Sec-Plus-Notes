# Monitoring Data

## 1. File Integrity Monitoring (FIM)

### Concept
- **Definition:** FIM monitors critical system and application files for any unauthorized or unexpected changes.
- **Examples of Files:**
  - **Data Files, Cache:** These change frequently.
  - **Application Executables, Libraries, Operating System Files:** Should remain static unless intentionally updated.

### Purpose
- **Objectives:**
  - Monitor important operating system and application files.
  - Detect when changes occur in files that should not be modified.
  - Identify potential malware or unauthorized access by checking for modifications to core system components.

### Implementation/Tools
- **Windows - SFC (System File Checker):**
  - An on-demand utility.
  - Scans all critical OS files.
  - Checks for and replaces any modified versions with the original, good version.
- **Linux - Tripwire:**
  - A popular FIM tool.
  - Monitors file changes in real-time.
  - Alerts instantly if anything is altered.
- **Host-based Intrusion Prevention System (IPS):**
  - Many host-based IPS solutions include FIM capabilities.
  - Unlike network-based IPS, which monitors network traffic, a host-based IPS operates directly on the operating system.

## 2. Data Loss Prevention (DLP)

### Concept
- **Definition:** DLP systems are designed to prevent sensitive data from leaving an organization or being used inappropriately.
- **Goal:** Stop "data leakage" before attackers can access or transmit it.

### Types of Sensitive Data Monitored
- Social Security Numbers (SSNs)
- Credit Card Numbers
- Medical Records (PHI - Protected Health Information)
- Proprietary Business Information

### Challenges and Solutions
- **Data Sources and Destinations:** Data can originate from many sources and travel to various destinations, requiring comprehensive solutions.
  - Often requires multiple DLP solutions deployed in different locations.

### Deployment Types of DLP Systems

#### On Your Computer (Endpoint DLP)
- **Monitoring "Data in Use":**
  - Monitors data that is actively being processed or stored in memory.
  - Can control actions like copying data to external devices.

#### On Your Network (Data in Motion)
- **Monitoring "Data in Motion":**
  - Watches data as it traverses the network in real-time.
  - Can be integrated into Next-Generation Firewalls (NGFWs) or deployed as standalone appliances.

#### On Your Server (Data at Rest)
- **Monitoring "Data at Rest":**
  - Monitors files stored on file systems, databases, or other storage media.
  - Runs as software directly on the server or operating system.

### Specific DLP Use Cases

#### USB Blocking
- **Function:** Endpoint DLP feature that controls data transfers to/from USB devices.
- **Importance:**
  - USB drives are portable and can easily transfer data in or out, making them a significant threat vector.
- **Historical Example (US Department of Defense, November 2008):**
  - A worm virus named "agent.btz" replicated using USB storage, infecting DoD systems.
  - Result: The DoD banned removable flash media and storage devices across all devices.
  - Implementation: Local DLP agents were updated to handle USB blocking.
  - Resolution: The ban was lifted in February 2010, replaced with strict guidelines for USB usage.

#### Cloud-based DLP
- **Location:** Between users and the internet.
- **Mechanism:** Watches every byte of network traffic entering or leaving cloud services.
- **Advantages:**
  - No hardware or software to manage on-premises.
  - Ideal for monitoring applications and data hosted in the cloud.
- **Capabilities:**
  - Block custom-defined data strings (e.g., unique internal project codes, sensitive customer IDs).
  - Manage access to URLs to prevent unauthorized file transfers to cloud storage.
  - Block viruses and malware traversing the network to/from cloud resources.

#### DLP and Email
- **Risk Vector:** Email remains the most critical risk vector for both inbound threats (e.g., phishing, malware) and outbound data loss.
- **Function:**
  - DLP solutions check every email, both inbound and outbound, whether from internal or cloud-based systems.
- **Inbound Email Monitoring:**
  - Block emails containing specific keywords (e.g., "confidential," "proprietary").
  - Identify impostors by checking for spoofed sender addresses.
  - Quarantine suspicious messages before they reach user inboxes.

- **Outbound Email Monitoring:**
  - Block emails containing sensitive financial information (e.g., fake wire transfer requests, actual wire transfer details).
  - Prevent transmission of sensitive employee data (e.g., W-2 forms with SSNs and personal information).
  - Block any email containing sensitive data that should not leave the organization.

### Key Takeaways for Exam Preparation

1. **Distinguish FIM and DLP:**
   - **FIM:** Focuses on the integrity of system and application files, detecting unauthorized changes in static files.
   - **DLP:** Focuses on preventing sensitive data from leaving the controlled environment or being misused.

2. **Know FIM Tools:**
   - **SFC (Windows):** On-demand utility that scans and replaces corrupted/modified OS files.
   - **Tripwire (Linux):** Real-time monitoring tool that alerts for any file changes.
   - **Host-based IPS:** Often includes FIM functionality.

3. **Understand DLP Deployment Contexts (Data States):**
   - **Endpoint DLP:** On individual computers, monitors "data in use."
   - **Network DLP:** On the network perimeter, monitors "data in motion."
   - **Server DLP:** On servers, monitors "data at rest."
   - **Cloud-based DLP:** Integrates with cloud services to monitor data moving to/from/within the cloud.

4. **Key DLP Functions & Examples:**
   - **Content Inspection:** Analyzes content for predefined sensitive data patterns.
   - **Blocking/Alerting:** Can block transmissions, quarantine files, or generate alerts based on policy violations.
   - **USB Blocking:** A common endpoint DLP feature to prevent data exfiltration via portable storage.
   - **Email DLP:** Essential for preventing sensitive data leakage via email.
   - **Cloud DLP:** Addresses data security in cloud environments.

5. **Identify Critical Risk Areas:**
   - **Email:** Highly susceptible to inbound threats and outbound data loss.
   - **Removable Media (USB drives):** Easy vector for introducing malware or exfiltrating data.
   - **Cloud Storage:** As more data moves to the cloud, cloud-based DLP becomes crucial.

6. **"Data Leakage" vs. "Data Breaches":**
   - DLP primarily aims to prevent unintentional or unauthorized outflow of sensitive information, which can lead to security incidents (data breaches).
