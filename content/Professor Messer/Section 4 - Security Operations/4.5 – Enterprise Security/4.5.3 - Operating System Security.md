## Active Directory (AD)
- **Definition**: A centralized database for managing everything on a network, primarily used with Windows-based systems. It stores information about:
  - **Computers** and other devices.
  - **User Accounts**.
  - **File Shares**.
  - **Printers**.
  - **Security Groups**.
  - Any other network components.

### Key Functions
- **Authentication**: Manages user logins using AD credentials (username and password), providing a central source for user authentication.
- **Access Control**: Determines which users can access specific resources such as files or printers. Permissions can be assigned to individual users or groups, simplifying management.

### Common Uses by Help Desk
- Resetting passwords.
- Adding and removing user accounts.
- Managing access rights and permissions.

### Benefit
Simplifies and centralizes the management of users, devices, and resources in large Windows network environments.

## Group Policy (GP)
- **Purpose**: A powerful feature for managing and configuring operating system settings, application configurations, and user settings within an Active Directory environment. It overlays security policies on AD-managed computers and users.
  
### Types of Policies
- **Local Policies**: Apply to a single machine.
- **Domain Policies**: Apply across an entire domain, managed centrally.

### Management Tool
**Group Policy Management Editor**: A central console for configuring Group Policy settings.

### Configurable Settings (Examples)
- **Login Scripts**: Scripts that run when a user logs on to the network.
- **Network Configurations**: Such as Quality of Service (QoS) settings.
- **Security Parameters**: Password complexity, firewall rules, software restrictions, desktop customization, etc.

### Benefit
Provides comprehensive control through hundreds of configuration options, ensuring consistent enforcement of security and operational policies across the entire network. Administrators can set specific configurations or permissions for individual users, groups, or devices.

### Relationship to AD
Group Policy relies on Active Directory to apply policies to defined users and computers.

## Security-Enhanced Linux (SELinux)
- **Purpose**: A set of security patches and modules for the Linux kernel that adds a layer of mandatory access control.
  
### Addressing Limitations of Discretionary Access Control (DAC)
- **DAC Definition**: Users have discretion over assigning rights and permissions to their own resources, such as files and directories.
- **Risk in DAC**: If a user account is compromised, the attacker gains full control over the affected resources.

### Introducing Mandatory Access Control (MAC)
- **MAC Definition**: All rights and permissions are assigned by a central administrator, not by the users or owners of the resource.
- **MAC Principle**: The system enforces access policies based on security labels assigned to subjects (users, processes) and objects (files, devices). Users cannot override these policies.

### Key Principles/Benefits of SELinux (MAC)
- **Limits Application Access**: Restricts what applications can do, even if they run as a privileged user.
- **Enforces Least Privilege**: Users and applications are granted only the minimum necessary permissions to perform their specific functions.
- **Limited Scope for Breaches**: If a security issue or breach occurs, the malicious code will have limited scope of actions due to SELinux policies.

### Nature
- **Open source**.
- Included as an option with many Linux distributions such as Red Hat, Fedora, and CentOS.

## Exam Takeaways

1. **Active Directory (AD) is a central identity and access management system for Windows networks.**
   - **Key Role**: Provides centralized authentication and access control for users and devices.
   - **What it contains**: Users, computers, groups, printers, file shares—essentially everything on the Windows network.
   - **Practical Use**: Used by help desks for password resets, account management, and basic permission settings.

2. **Group Policy (GP) is a primary tool for managing configurations and security policies in a Windows domain.**
   - **Relationship to AD**: GP applies policies to users and computers defined in Active Directory.
   - **Capabilities**: Configures a wide range of settings including login scripts, network configurations (like QoS), and critical security parameters (e.g., password policies, firewall rules, software restrictions).
   - **Benefit**: Enables consistent and scalable management of security and operational settings across many devices and users from a single console.

3. **Security-Enhanced Linux (SELinux) is a critical security enhancement for Linux systems.**
   - **Why it's needed**: Adds mandatory access control to the Linux kernel, addressing limitations of discretionary access control.
   - **What it provides**: Enforces least privilege and limits the damage from breaches by constraining application actions with SELinux policies.
   - **Core Security Principles**:
     - **Least Privilege**: Applications and users only get the minimum permissions needed for their tasks.
     - **Containment**: Limits the impact of a security breach, as compromised components are constrained by SELinux policies.
   - **Nature**: Open-source and commonly integrated into major Linux distributions.

4. **Understand the difference between DAC and MAC:**
   - **DAC**: User-centric control over resources; flexible but potentially less secure.
   - **MAC**: Administrator-centric control, overriding user discretion; stricter and more secure, often used in high-security environments.

5. **The concept of "Least Privilege" is fundamental to operating system security.**
   - Granting only the necessary permissions reduces the attack surface and limits the impact of a breach. Both Group Policy (in Windows) and SELinux (in Linux) are mechanisms to help enforce least privilege.
