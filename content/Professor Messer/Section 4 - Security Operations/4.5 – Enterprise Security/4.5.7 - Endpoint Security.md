# Endpoint Security - Overview

## Definition
- **Definition:** The device used by the user to access applications and data.
  - **Examples:** Desktops, laptops, mobile devices (smartphones, tablets).
- **Vulnerability:** Applications running on these devices can be exploited by attackers to gain access to user data or sensitive information.

## Goal of Endpoint Security
- **Objective:** To stop attackers from gaining unauthorized access to user data.
- **Challenges:** Many different platforms need monitoring and protection. A multi-faceted approach, such as Defense in Depth, is essential.

## Edge vs. Access Control

### 2.1. Control at the Edge
- **Definition:** Security measures implemented at the network's boundary where the internal network meets the external internet.
- **Primary Tool:** Firewalls.
  - Managed through static firewall rules that monitor all traffic (inbound and outbound).

### 2.2. Access Control
- **Definition:** Limiting a device's access to specific types of data, regardless of its location.
- **Flexibility:** Access can be based on various parameters such as:
  - By user or user group.
  - By location where the user/device is located.
  - By application which are allowed to access data.
- **Dynamic Nature:** Access controls can be easily revoked or changed.

## Posture Assessment

### Problem
- You cannot fully trust everyone's computer, especially in BYOD (Bring Your Own Device) policies.
- Devices may have malware infections, missing anti-malware software, or unauthorized applications.

### Purpose
- To constantly check systems to ensure they meet the latest security standards before granting network access.
- **When to Perform:** Ideally during initial network connection or remote login.

### Health Checks (Parameters Checked)
- Is it a trusted device?
- Is antivirus running and updated with the latest signatures?
- Are corporate applications installed and up-to-date?
- Disk encryption for mobile devices.

## Types of Posture Assessment Agents

### Persistent Agents
- **Definition:** Permanently installed on a system.
- **Functionality:** Can run checks at any time, require periodic updates, monitor files and applications continuously.

### Dissolvable Agents
- **Definition:** Runs only during the posture assessment.
- **Functionality:** Terminates and removes itself completely after use. Typically used for temporary checks.

### Agentless NAC (Network Access Control)
- **Definition:** Integrated with directory services like Active Directory.
- **Functionality:** Checks are made during login and logoff, cannot be scheduled for continuous monitoring due to lack of a local agent.

## Failing Your Assessment

### Consequence
- If a device fails the posture assessment, it is considered too dangerous for full network access.

### Remediation Steps
1. **Quarantine Network:** The device is isolated (e.g., placed on its own VLAN).
2. **Notify Administrators:** Security teams are alerted.
3. **Limited Access:** Device given limited access to fix issues (e.g., download antivirus updates, install corporate apps).
4. **Re-assessment:** User must pass the posture assessment again before gaining full network access.

## Endpoint Detection and Response (EDR)

### 5.1. Detect a Threat
- **Challenge:** Over a million new virus variants daily; traditional antivirus struggles to keep up.
- **Definition:** A modern method of threat protection that scales with increasing threats.
- **Key Functions:**
  - **Behavioral Analysis, Machine Learning, and Process Monitoring:** Identifies suspicious activity beyond traditional signatures.

### 5.2. Investigate the Threat
- **Root Cause Analysis:** Understands how the threat entered the system, actions taken, removal methods, and preventive measures.

### 5.3. Respond to the Threat
- **Automated Response Capabilities:**
  - **Isolate the System:** Disconnects infected devices from the network.
  - **Quarantine the Threat:** Contains malware.
  - **Rollback to a Previous Configuration:** Restores systems to known good states.

## Extended Detection and Response (XDR)

### An Evolution of EDR
- **Definition:** Builds on EDR to address its limitations, improving detection rates and investigation times.
- **Improvements:**
  - Reduces missed detections and false positives.
  - Correlates data from multiple sources such as endpoints, networks, and cloud environments.

### Key Capabilities
- **Network-Based Detection:** Investigates network anomalies.
- **Correlation of Data:** Gathers and analyzes diverse sources to provide a broader context for threat detection.

## User Behavior Analytics (UBA)

### Role in XDR
- **Definition:** Extends anomaly detection by focusing on user activity.
- **How it Works:**
  - **Watches users, hosts, network traffic, data repositories.**
  - **Baseline Creation:** Establishes typical user patterns over time through analysis.
  - **Anomaly Detection:** Uses rules, pattern matching, and statistical analysis to detect deviations from the baseline.

### Goal
- Real-time detection of unusual activity to catch threats early before they escalate into larger issues.

# Exam Takeaways

1. **Endpoint Definition & Importance:**
   - An endpoint is any user-facing device (desktop, laptop, mobile). Robust security is critical due to the high risk of attack.
2. **Defense in Depth:**
   - Layered approach using various controls is essential for comprehensive protection.
3. **Distinguish Edge vs. Access Control:**
   - **Edge Control:** Focuses on network perimeter (firewalls, static rules).
   - **Access Control:** Focuses on who can access what data from where and how (dynamic, user/group/location/app-based rules).

4. **Posture Assessment Necessity:**
   - Posture assessment ensures devices meet security standards before connecting to the network.
5. **Types of Posture Assessment Agents:**
   - **Persistent Agents:** Permanently installed for continuous monitoring.
   - **Dissolvable Agents:** Run during assessments and self-remove.
   - **Agentless NAC:** Integrated with directory services, runs during login/logoff.

6. **Consequences of Failed Posture Assessment:**
   - Device isolation, administrator notification, limited access for remediation, re-assessment before full network access.

7. **EDR - Beyond Traditional AV:**
   - EDR detects threats using behavioral analysis, machine learning, and process monitoring.
8. **XDR - The Next Level:**
   - XDR correlates data from multiple sources (endpoints, networks, cloud) for broader threat detection and faster investigations.
9. **User Behavior Analytics (UBA):**
   - Establishes baselines of normal user activity to detect anomalies early, providing crucial insights for threat detection.
