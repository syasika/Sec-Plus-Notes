# Hardening Techniques

## Introduction to System Hardening
- **Definition**: Making devices more secure by reducing vulnerabilities. This applies to various operating systems like Windows, Linux, iOS, Android, and others, with a focus on servers and endpoint devices.

## 1. System Hardening on Servers
### A. Updates
- **Importance**: The first and most critical step.
- **Action**: Always apply operating system updates, service packs, and security patches.
- **Frequency**: Manufacturers like Microsoft typically release patches monthly.

### B. User Accounts
- **Password Policies**:
  - **Minimum password lengths**: Enforce a minimum number of characters.
  - **Complexity**: Require a mix of uppercase, lowercase, numbers, and special characters.
- **Account Limitations (Principle of Least Privilege - PoLP)**:
  - Not every account should have administrator rights.
  - Each user should only have the necessary permissions to perform their job functions.

### C. Network Access and Security
- **Limit Network Access**:
  - Restrict who can access the system across the network using IP address ranges.
  - Unauthorized IP addresses should be denied access.
- **Monitor and Secure**:
  - Utilize anti-virus and anti-malware software.
  - Employ endpoint detection mechanisms.

## 2. Encryption
- **Purpose**: Prevent unauthorized access to application data files.

### A. File System Encryption
- Encrypts individual files or folders.
- **Example**: Windows Encrypting File System (EFS).

### B. Full Disk Encryption (FDE)
- Encrypts the entire drive, including the operating system and user documents.
- **Examples**: Windows BitLocker, macOS FileVault.

### C. Encrypt Network Communication
- **Methods**:
  - **Virtual Private Networking (VPN)**: Encrypts all network traffic between two points.
  - **Application Encryption**: Applications may have built-in encryption (e.g., HTTPS for web browsing).

## 3. The Endpoint
- **Definition**: Refers to the user's access point, such as a desktop, laptop, or mobile device.
- **User's Access**: Includes applications and data.
- **Threats**: Need to stop both inbound attacks (from external sources) and outbound attacks (malware on the endpoint attacking other systems).
- **Platforms**: Apply appropriate security for various platforms with different operating systems and applications.
- **Protection is Multi-faceted**: Employing multiple security tools and utilities is known as **Defense in Depth**.

## 4. Endpoint Detection and Response (EDR)
- **Definition**: A modern method of threat protection designed to scale with the increasing number of threats, such as over 1 million new malware variants daily.

### A. Detect a Threat
- Goes beyond traditional signatures for detection.
- **Methods**:
  - **Behavioral Analysis**: Monitors user and application actions to identify malicious patterns.
  - **Machine Learning**: Rapidly identifies malware based on learned patterns.
  - **Process Monitoring**: Continuously watches all processes for unusual or malicious activity.
- **Implementation**: Uses a lightweight agent installed directly on the endpoint.

### B. Investigate the Threat
- Performs root cause analysis on detected threats.
- EDR conducts additional studies to determine if suspicious processes are malicious or legitimate.

### C. Respond to the Threat
- **Immediate Action**: EDR can automatically take action without human intervention (API-driven).
- **Actions**:
  - **Isolate the system**: Prevent further spread of infection.
  - **Quarantine the threat**: Isolate malicious files.
  - **Rollback to a previous configuration**: Restore the system to a clean state.
- **Reporting**: Reports all information back to a central management console.

## 5. Host-based Firewall
- **Definition**: A software-based firewall that runs directly on an individual endpoint device (personal firewall).
- **Functionality**:
  - **Allow/Disallow Traffic**: Controls incoming and outgoing application traffic.
  - **Application-level Control**: Manages traffic based on the application process.
  - **Visibility**: Can view all data before or after encryption, offering complete visibility.
- **Security Benefits**:
  - Identifies and blocks unknown processes, stopping malware before it can execute.
  - Can be configured to automatically block unusual traffic until administratively approved.
- **Management**: Can be managed centrally despite running on individual systems.

## 6. Host-based Intrusion Prevention System (HIPS)
- **Definition**: A system that recognizes and blocks known attacks on an individual device.
- **Integration**: Often built into endpoint protection software like EDR or anti-malware.
- **Capabilities**:
  - Secures OS and application configurations.
  - Validates incoming service requests.
- **HIPS Identification Methods**:
  - **Signatures**: Matches known attack patterns.
  - **Heuristics**: Uses rules and algorithms to detect suspicious behavior.
  - **Behavioral Analysis**: Monitors system behavior for anomalies.
- **Monitored Activities**: Buffer overflows, registry updates, writing files to critical system folders (e.g., Windows folder), access to non-encrypted data.
- **Response**: Sends alerts and blocks malicious activity.

## 7. Minimize Open Ports and Services
- **Inherent Risk**: Every open port is a potential vulnerability.
- **Best Practice**:
  - Actively close unnecessary ports and services.
  - Use tools like Nmap to verify.
- **Verification**: Ongoing monitoring is crucial.

## 8. Default Password Changes
- **Vulnerability**: Every network device (routers, switches, firewalls, access points) and many applications have default management interfaces with default credentials.
- **Risk**: Attackers can easily find these default settings. These interfaces often contain sensitive data.
- **Best Practice**:
  - Immediately change all default passwords upon installation or deployment.
  - Some systems will prompt for a password change, but many do not.
- **Additional Security**:
  - Require additional logon steps.
  - Implement multi-factor authentication (MFA).
  - Integrate with third-party/centralized authentication systems.

## 9. Removal of Unnecessary Software
- **Inherent Risk**: All software contains bugs; some are security vulnerabilities.
- **Patching Challenge**: Every application often has a unique patching process, making it challenging to manage ongoing updates and ensure everything is secure.
- **Best Practice**: Remove all unused software.
- **Benefit**: Reduces the attack surface and overall security risk.

# Takeaways for Exam

1. **Hardening is Multi-Layered (Defense in Depth)**: No single solution provides complete security. A combination of techniques across different layers is essential.
2. **Regular Updates are Non-Negotiable**: OS and application patches are critical to address known vulnerabilities. This is often the first line of defense.
3. **Strong Password Policies & Least Privilege**: User account security is fundamental. Enforce complex passwords and limit user permissions to only what's necessary for their role.
4. **Encryption Protects Data at Rest and in Transit**: Understand the difference between file system encryption (EFS) and full disk encryption (FDE - BitLocker, FileVault), and the importance of encrypting network communications (VPN, HTTPS).
5. **EDR is the Next Generation of Endpoint Protection**:
  - Goes beyond traditional signature-based antivirus.
  - Uses behavioral analysis, machine learning, and process monitoring for detection.
  - Crucially, it can investigate (root cause analysis) and respond automatically (isolate, quarantine, rollback) to threats via API.
6. **Host-based Firewalls & HIPS Provide Granular Endpoint Control**:
  - Host-based firewalls control incoming/outgoing traffic at the application level on the endpoint itself.
  - HIPS actively monitors OS and application behavior for suspicious activity, including low-level changes like buffer overflows or registry modifications.
7. **Minimize Open Ports and Services**: Every open port is a potential vulnerability. Actively close unnecessary ports and services using tools like Nmap.
8. **Always Change Default Credentials**: Default passwords are a huge security risk. Change them immediately on all devices and applications. Implement MFA where possible.
9. **Reduce Attack Surface by Removing Unused Software**: Less software means fewer potential bugs and vulnerabilities to manage. Uninstall anything not essential.
