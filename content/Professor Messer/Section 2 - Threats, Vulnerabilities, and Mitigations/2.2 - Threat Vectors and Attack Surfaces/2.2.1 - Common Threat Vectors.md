# Introduction to Threat Vectors

## Overview
- **Threat Vector (Attack Vector):** A method used by attackers to gain access to or infect a target system. Attackers constantly look for new ways to exploit systems, while IT security professionals work to monitor and mitigate these vectors.

---

## Message-Based Vectors

### Email
- **Malicious Links:** Phishing emails often contain links that lead to malicious sites.
- **Attachments:** Files attached to emails can contain malware.
  
### SMS (Short Message Service)
- **Smishing Attacks:** Text messages designed to trick users into clicking on malicious links or providing personal information.

### Phishing Attacks
- **Human Interaction:** Exploits the tendency to trust and click on links. Common in emails, texts, and instant messages (IMs).
- **Example:** A phishing email might impersonate a bank and ask for login credentials by pretending to be an update request.

### Malware Delivery
- **Email Delivery:** Attachments or malicious links can download malware.
- **Prevention:** Always scan attachments and avoid launching untrusted links.

### Social Engineering Attacks
- **Invoice Scams:** Fake invoices sent via email, asking for payments.
- **Cryptocurrency Scams:** Attempts to gain access to cryptocurrency wallets through fraudulent methods.

**Example:** A text message claiming to be from USPS might provide a malicious link to "resolve" a package delivery issue.

---

## Image-Based Vectors

### Scalable Vector Graphics (SVG)
- **XML Format:** An image format described in XML, which can contain embedded HTML and JavaScript.
- **Security Concerns:**
  - **HTML Injection:** Malicious HTML code within the SVG file.
  - **JavaScript Attack Code:** Can lead to Cross-Site Scripting (XSS) attacks.

**Prevention:** Browsers must validate inputs for SVG files to prevent running malicious code. Some browsers allow disabling certain image types.

**Example:** An attacker could embed JavaScript in an SVG to exploit vulnerabilities in web browsers.

---

## File-Based Vectors

### Beyond Executables
- **PDFs and Compressed Archives (ZIP/RAR):** These can contain hidden malware.
- **Office Documents with Macros/Add-ins:** Macros or add-ins that run automatically when the document opens, potentially downloading or executing malicious code.

---

## Voice Call Vectors

### Vishing (Voice Phishing)
- **Tactics:** Impersonating banks, tech support, etc., over the phone to trick users into divulging personal information.
  
### Spam Over IP
- **Techniques:** Sending spam through VoIP services to target individuals or organizations.

### War Dialing and Call Tampering
- **War Dialing:** Attacking a range of phone numbers with automated calls.
- **Call Tampering:** Manipulating voicemail systems to gain unauthorized access.

---

## Removable Device Vectors

### USB Drives
- **Bypass Firewalls:** USB drives can bypass network security measures and infect air-gapped networks.
- **Hacker on a Chip (e.g., Rubber Ducky):** USB devices that run scripts or execute commands.
- **Data Exfiltration:** Used to transfer data from one system to another.

---

## Vulnerable Software Vectors

### Client-Based vs. Agentless
- **Client-Based:** Local executables that can be exploited if not kept up-to-date.
- **Agentless:** Server-side applications that require regular patching and updates to prevent vulnerabilities.

**Prevention:** Regular software updates, strong patch management policies, and awareness of zero-day exploits.

---

## Unsupported Systems Vectors

### Unpatched Outdated OS/Software
- **Risk:** Lack of security patches and updates leaves systems vulnerable.
  
**Prevention:** Maintain an up-to-date inventory of all systems to ensure they are patched and supported.

---

## Unsecure Network Vectors

### Wireless Networks
- **Outdated Security Protocols:** Use WPA3 for better protection; avoid WEP, WPA, or WPA2.
- **Open or Rogue APs:** Unauthorized access points set up by attackers.

### Wired Networks
- **Unsecured Interfaces:** Lack of authentication on network ports.
  
**Prevention:** Implement 802.1X authentication to secure wired connections.

### Bluetooth
- **Reconnaissance:** Used to discover devices and gather information.
- **Implementation Vulnerabilities:** Flaws in device implementation can be exploited by attackers.

---

## Open Service Ports

### Attack Surface Expansion
- **Every Open Port:** Represents an opportunity for exploitation due to application vulnerabilities or misconfigurations.

**Prevention:** Proper firewall rules to limit access only to necessary services and trusted sources.

---

## Default Credentials Vectors

### Default Passwords
- **Easily Guessable:** Default usernames and passwords (e.g., admin/admin) are widely known and often left unchanged.
  
**Prevention:** Change default credentials immediately after setting up a new device.

---

## Supply Chain Vectors

### Managed Service Providers (MSPs)
- **Centralized Access:** MSPs manage networks for multiple customers. Compromising an MSP can grant attackers access to all customer networks.

### Vendor-Related Threats
- **Counterfeit Networking Equipment:** Fake hardware with backdoors or reduced functionality.
- **Example:** In 2020, fake Cisco Catalyst switches were identified and could have contained malicious software.

---

# Takeaways for Exam

1. **Define Threat/Attack Vector:**
   - Understand it as the method used by attackers to exploit systems.

2. **Categorize Vectors:**
   - **Message-based:** Email, SMS, IM (focus on phishing and social engineering tactics, malicious links/attachments).
   - **Image-based:** Primarily SVG files containing embedded HTML/JavaScript; understand the browser's role in validation.
   - **File-based:** Beyond executables, think PDFs, compressed archives (ZIP/RAR), Office documents with macros/add-ins.
   - **Voice call:** Vishing, spam over IP, war dialing, call tampering.
   - **Removable device:** USB drives bypassing firewalls, infecting air-gapped networks, acting as keyboards (e.g., Hacker on a chip), and facilitating data exfiltration.
   - **Vulnerable software:** Client-based (local executables) vs. Agentless (server-side apps). Emphasize patching for known vulnerabilities and the danger of zero-day exploits.
   - **Unsupported systems:** Unpatched, outdated OS/software; critical risk due to lack of security fixes; importance of inventory.
   - **Unsecure network:** Wireless (outdated protocols like WEP/WPA2, rogue APs), Wired (no 802.1X), Bluetooth (reconnaissance, vulnerabilities).
   - **Open service ports:** Every open port is an opportunity due to application vulnerabilities or misconfigurations; importance of firewall rules.
   - **Default credentials:** Easily guessable/discoverable passwords; always change them immediately.
   - **Supply chain:** Tampering with hardware/software during manufacturing or distribution; compromising vendors (like MSPs or contractors) to gain access to target networks (e.g., Target breach).

3. **Key Concepts & Terms:**
   - Phishing, Smishing, Vishing
   - Malware
   - Social Engineering
   - SVG (Scalable Vector Graphics), XML, HTML Injection, JavaScript Attack Code, Cross-Site Scripting (XSS)
   - Air-gapped Networks
   - Hacker on a chip (e.g., Rubber Ducky)
   - Data Exfiltration
   - Vulnerability, Zero-Day Exploit
   - Patching
   - Unsupported Systems
   - WPA3 (upgrade from WEP/WPA/WPA2)
   - 802.1X authentication
   - Open Port, Attack Surface
   - Default Credentials
   - Supply Chain Attack, Managed Service Provider (MSP)

4. **Prevention Strategies:**
   - User Education: Training users to recognize phishing, smishing, social engineering.
   - Technical Controls:
     - Scanning: Email attachments, downloaded files.
     - Input Validation: For image and web content.
     - Patch Management: Regular updates for all software and operating systems.
     - Network Security: Strong wireless protocols (WPA3), 802.1X for wired, securing Bluetooth.
     - Firewalls: Limiting open ports and controlling traffic.
     - Access Control: Changing default credentials, strong password policies.
     - Inventory Management: Identifying and addressing unsupported systems.
     - Vendor Management: Vetting third-party providers and ensuring their security practices.

5. **Attacker Mindset:** Attackers constantly look for new ways to exploit system weaknesses or human trust. They value any entry point, no matter how small (e.g., a $10 USB drive).

By focusing on these points, students can build a comprehensive understanding of common threat vectors and be well-prepared for an exam.
