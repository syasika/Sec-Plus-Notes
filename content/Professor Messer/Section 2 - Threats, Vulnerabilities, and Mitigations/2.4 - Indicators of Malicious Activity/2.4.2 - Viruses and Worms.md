# Viruses and Worms

## Overview
- **Definition**: 
  - **Viruses**: Malware that can reproduce itself. Requires user execution to start (e.g., clicking a link, running an executable).
  - **Worms**: Malware that self-replicates without needing user interaction.
  
- **Vulnerabilities**:
  - Viruses spread through file systems or across networks once active.
  - Worms use the network as a transmission medium to rapidly spread and take over many systems.

## Key Distinctions
### Virus vs. Worm

#### Virus
- **Definition**: Malware that requires user execution to start.
- **Spread Mechanism**:
  - Spreads through file systems or across networks once active.
  - Examples: Program viruses, boot sector viruses, script viruses, and macro viruses.

#### Worm
- **Definition**: Self-replicating malware that spreads without needing user interaction.
- **Impact**: Causes widespread disruption and resource consumption.

## Types of Viruses

### Program Virus
- **Nature**: Part of an application (e.g., an infected `.exe` file).
- **Execution**: Runs when the infected application is executed.

### Boot Sector Virus
- **Nature**: Infects the Master Boot Record (MBR) or boot sector of a storage device.
- **Execution**: Automatically runs when the system boots, before the operating system loads. Difficult to detect and remove due to early execution.

### Script Virus
- **Nature**: Written in scripting languages like JavaScript, VBScript.
- **Impact**: Exploits vulnerabilities in scripting engines of OS or web browsers.

### Macro Virus
- **Nature**: Common in applications that support macros (e.g., Microsoft Office documents).
- **Execution**: Runs when the document is opened, exploiting vulnerabilities in how applications handle macros.

## Fileless Viruses

- **Definition**: A stealth attack that avoids traditional anti-virus detection.
- **Mechanism**:
  - Does not rely on files stored on disk; operates primarily in memory.
  - Never installed as a file or application in the traditional sense.
  
### Example Scenario
1. **Initial Access**: User clicks on a malicious link (e.g., in an email, on a website).
2. **Exploitation**: Website exploits a vulnerability in the browser, OS, or plugins.
3. **Payload Delivery**: Exploit launches a legitimate system tool like PowerShell and downloads the payload directly into RAM.
4. **Execution**: Malicious scripts or executables run in memory.
5. **Actions**: Performs malicious activities such as data exfiltration, file damage, or further infection.
6. **Persistence**: Adds an auto-start entry to the system's Registry (Windows) or a similar auto-load mechanism, pointing back to the original malicious website/payload.

## Defense Mechanisms

### Viruses
- **Detection and Prevention**:
  - Use anti-virus software with up-to-date signature files.
  - Educate users not to click suspicious links or run unknown executables.

### Worms
- **Detection and Prevention**:
  - Deploy network firewalls to block propagation attempts.
  - Implement Intrusion Detection Systems (IDS) and Intrusion Prevention Systems (IPS) to detect and prevent worm traffic.
  - Regularly patch systems to fix vulnerabilities, such as EternalBlue for WannaCry.

### Fileless Viruses
- **Detection**:
  - Use behavioral-based anti-malware solutions.
  - Employ memory scanning techniques to identify suspicious activity in legitimate system tools like PowerShell.
  - Keep the operating system and applications patched to prevent exploitation.

## Impact

### Viruses
- Can cause various issues, from annoyance to data loss.
- Depend on user error for spread; can be mitigated with proper education and anti-virus software.

### Worms
- Lead to rapid, widespread network outages and resource consumption.
- Can install further malware like ransomware, as seen with WannaCry.

## Specifics to Remember

- **Boot Sector Viruses**: Infect the boot sector and run before the OS loads.
- **Macro Viruses**: Common in MS Office applications, exploit application-specific scripting languages.
- **WannaCry**: A famous example of a worm combined with ransomware, exploiting EternalBlue vulnerability.

By understanding these distinctions and mechanics, you can better prepare for exam questions on virus and worm concepts.
