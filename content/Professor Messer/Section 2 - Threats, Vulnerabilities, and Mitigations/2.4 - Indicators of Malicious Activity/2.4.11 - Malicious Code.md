# Malicious Code

## Overview

**Definition**: Refers to software designed to perform malicious actions without the owner's consent.

**Source**: 
- **Video Title:** Malicious Code

## Exploiting a Vulnerability 

### Attacker Techniques

An attacker can use various techniques to gain access to systems:
- **Social Engineering**: Tricking users into revealing information or access.
- **Default Credentials**: Using pre-set usernames and passwords that haven't been changed on new equipment.
- **Misconfiguration**: Errors in system setup that leave doors open.

### Characteristics of these Techniques

These techniques generally don't require advanced technical skills. They exploit situations where "the door is already unlocked" due to human error or oversight, requiring some knowledge of the organization or users but not deep technical expertise.

### Attacking Well-Secured Systems

When users are not susceptible to social engineering and devices are properly configured with changed credentials, attackers need different methods:
- **Exploiting with Malicious Code**: This requires more technical know-how.
- *(Analogy: Knocking pins out of a door hinge vs. walking through an unlocked door)*

## Malicious Code Overview 

### Attacker's Approach

Attackers use any opportunity to deploy malicious code, and the types are varied:
- **Executable Files**: Standalone programs designed to perform malicious actions.
- **Scripts**: Code snippets that run within other applications or environments (e.g., JavaScript, PowerShell scripts).
- **Macro Viruses**: Malicious code embedded in document macros (e.g., Word, Excel).
- **Worms**: Self-replicating malware that spreads across networks.
- **Trojan Horse**: Malware disguised as legitimate software, tricking users into installing it.

### Protection Strategies

Protection against malicious code requires a strong, multi-layered defense from various sources:
- **Anti-malware/Antivirus**: Blocks executables, scripts, macro viruses, etc.
- **Firewall**: Blocks known malicious traffic passing through the network.
- **Continuous Updates and Patches**: Closes vulnerabilities in software and operating systems.
- **Secure Computing Habits**: User training to prevent social engineering (e.g., not clicking unknown links, not giving out info over the phone).

## Malicious Code Examples 

### WannaCry Ransomware
- **Type of Code**: Executable ransomware.
- **Vulnerability Exploited**: A vulnerability in **Windows SMBv1** (Server Message Block version 1).
- **Method**: Allowed for arbitrary code execution, meaning the attacker could run any software they desired on the victim's machine.
- **Impact**: Installed ransomware, encrypting files and demanding payment.

### British Airways Cross-Site Scripting (XSS)
- **Type of Code**: Malicious JavaScript code.
- **Vulnerability/Method**: Attackers gained access to the British Airways website and placed 22 lines of malicious JavaScript code on checkout pages.
- **Impact**: Stole credit card information from approximately 380,000 victims.

### Estonian Central Health Database (SQL Injection)
- **Type of Code**: Malicious SQL injection commands.
- **Vulnerability/Method**: Exploited a vulnerability in the database's input validation, allowing attackers to inject SQL commands.
- **Impact**: Breached all healthcare information for an entire country (Estonia), gaining access to the complete database.

## Takeaways for Exam Preparation

1. **Distinguish Vulnerability Exploitation Types**:
    - **Non-technical (User-centric)**: Social Engineering, Default Credentials, Misconfiguration. These are "open doors" due to human error or lack of basic security hygiene and don't require advanced technical skills from the attacker.
    - **Technical (System-centric)**: Exploiting with Malicious Code. This targets software flaws and requires specialized technical knowledge.

2. **Understand "Malicious Code" as a Broad Category**: It encompasses various forms like executables, scripts, Macro Viruses, Worms, and Trojan Horse. Attackers will use whatever form is most effective for a given vulnerability.

3. **Layered Defense is Crucial**:
    - **Technical Controls**: Anti-malware, Firewall, Continuous Updates and Patches.
    - **Administrative Controls**: Secure Computing Habits (user training).

4. **Know Key Malicious Code Examples and Their Mechanisms**:
    - **WannaCry**: An executable exploiting a specific Windows SMBv1 vulnerability for arbitrary code execution (ransomware).
    - **British Airways Data Breach**: Cross-Site Scripting (XSS) using malicious JavaScript injected into web pages to steal credit card information.
    - **Estonian Health Database Breach**: SQL Injection to access sensitive database information.

5. **Focus on the *How* of Each Attack**:
    - What type of malicious code was used?
    - What specific vulnerability or weakness was exploited?
    - What was the ultimate impact or goal of the attacker?

6. **Prevention is Key**:
    - Regular patching.
    - Strong passwords (changing defaults).
    - Proper configuration.
    - User security awareness training.
