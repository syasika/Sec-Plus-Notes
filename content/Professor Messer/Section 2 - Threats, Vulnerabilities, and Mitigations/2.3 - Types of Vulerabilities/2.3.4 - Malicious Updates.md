# Malicious Updates - Professor Messer Notes

## Importance of Software Updates
- **Purpose:** Always keep your operating systems and applications updated to protect against vulnerabilities and security threats.
- **Benefits:**
  - Includes bug fixes.
  - Provides critical security patches.

### Goal:
Avoid vulnerabilities and security problems associated with older code.

## Security Concerns with the Update Process Itself
- **Fundamental Risk:** Installing an update is similar to installing a new application.
- **Threat:** The update itself might contain [[Malware|malicious software]].
- **Attack Vector:** Attackers can embed their malicious code within what appears to be a legitimate update.

### Key Point:
Not every update is equally secure.

## Best Practices for Safe Updating

### a. Always Have a Known-Good Backup
- **Rationale:** Essential before making any system changes.
- **Benefit:** Allows you to revert to a previous, working configuration if the update causes issues or introduces malware.
- **Professor Messer's Emphasis:** "Did I mention the backup?" (Highlights its critical importance).

### b. Install from Trusted Sources
- **Verification:** Ensure the source of the update is reputable and commonly used for that software.
  - **Beware of Pop-ups:**
    - A message appearing when you *first* start a browser (e.g., Chrome) before visiting any other site might be legitimate (browser's own update check).
    - However, a *random pop-up* during normal web browsing instructing you to update (e.g., "Update Flash Player," "Your browser is old, click here to update") is highly suspicious and likely malicious.
- **Confirm the Source:**
  - A random pop-up during web browsing is generally *not* legitimate.
  - **Action:** Visit the developer's official site directly.
  - **Rule of Thumb:** Do not trust a random update button or a randomly downloaded file from an untrusted site.

### c. Digital Signatures
- **Functionality:** Many operating systems (OS) will only allow the installation of applications that have been digitally signed.
- **Process:** During installation, the OS verifies the digital signature to confirm the application's authenticity and integrity (i.e., it hasn't been tampered with since the developer signed it).
- **Trust Level:** A valid digital signature from a known developer (e.g., Microsoft, Adobe, Google) provides a high level of trust in the update's legitimacy.
- **Warning:** Do not disable your security controls (like signature checks) to install unsigned software.

## Automatic Updates
- **Mechanism:** The application updates itself directly.
- **Security Features:** Often includes built-in security checks and digital signatures.
- **Trust Level:** Generally considered relatively trustworthy as the update comes directly from the developer.
- **Caveat:** Even automatic updates are *not a 100% guarantee* of legitimacy, as demonstrated by the [[SolarWinds Orion supply chain attack]].

## Case Study: SolarWinds Orion Supply Chain Attack
- **Reported:** December 2020.
- **Vulnerability:** Attackers gained access to SolarWinds' *development system*.
- **Attack Method:** Malicious code was *added directly to the legitimate updates* for their Orion software.
- **Deception:** The malicious updates followed the normal update process and were digitally signed by SolarWinds, making them appear completely legitimate to users.
- **Impact:**
  - SolarWinds Orion is high-end management software used by many large organizations worldwide.
  - Attackers gained access to hundreds of government agencies and companies.
  - They achieved full control over the systems running Orion and were able to move laterally to other systems within those organizations.
- **Significance:** This was a rare but highly sophisticated [[Supply Chain Attack]], demonstrating that even trusted developers and their update processes can be compromised, leading to widespread distribution of malware.

## Key Takeaways for Exam

1. **Prioritize Updates, but with Caution:** Always update your OS and applications promptly for security, but be aware that the update process itself is a potential attack vector.
2. **Backup is Paramount:** Before any update, ensure you have a [[Backup|known-good backup]]. This is your primary defense against failed updates or malicious installations.
3. **Validate Sources Rigorously:**
  - Avoid clicking random "update" pop-ups during web browsing.
  - Always go directly to the official developer's website to download updates.
  - Do not trust random downloaded files.
4. **Understand Digital Signatures:**
  - Digital signatures verify the authenticity and integrity of software.
  - They provide a high level of trust, but are not infallible (as shown by SolarWinds).
  - Never disable your OS security controls to install unsigned applications.
5. **Automatic Updates are Generally Safer, but Not Foolproof:**
  - Built-in automatic update mechanisms from trusted developers are generally more secure than manual downloads from unverified sources.
  - However, the [[SolarWinds Orion supply chain attack]] highlights that even these trusted channels can be compromised if the developer's infrastructure is breached.
6. **Recognize Supply Chain Attacks:** Be aware that attackers can inject malicious code into *legitimate* software updates from trusted vendors by compromising their development or distribution channels. This is a sophisticated threat that bypasses many traditional security checks.
