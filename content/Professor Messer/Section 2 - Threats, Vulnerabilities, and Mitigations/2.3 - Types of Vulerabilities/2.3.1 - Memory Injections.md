# Memory Injections

## Introduction: Finding Malware in Memory
All software on a computer, including malware, **runs in memory**. Nothing executes unless it's loaded from disk into memory and processed by the CPU. Therefore, **malware must get into memory to operate**. **Memory forensics** is the discipline of examining memory to find malicious code.

## Contents of Memory
Memory contains various running processes and their components. When analyzing memory, you'll find:
- **DLLs (Dynamic Link Libraries)**: Windows libraries containing code and data that are often shared by multiple applications.
- **Threads**: Individual units of execution within a process.
- **Buffers**: Areas of memory used to temporarily store data for processes.
- **Memory management functions**: System functions responsible for allocating, deallocating, and managing memory space for processes.

## Malware Hiding Strategies
Malware has several ways to operate in memory:
1. Runs as its own process: This is generally easier for security software to detect because it's an unfamiliar or suspicious process.
2. Injects itself into a legitimate process: This is the core concept of "memory injection" and is a more stealthy approach.

## What is Memory Injection?
**Definition**: The act of **adding malicious code into the memory space of an existing, legitimate process**.
**Goal**: To hide malware inside a process that is expected to be running and trusted by the operating system and security software. The malware then operates under the guise of this legitimate process.

### Advantages for Attackers
Memory injection offers significant benefits to attackers:
- **Evasion of Detection**: Traditional anti-malware solutions often monitor for suspicious *new processes* or *known malicious process names*. By injecting into a legitimate process, the malware avoids creating its own suspicious process, making it harder to detect.
- **Privilege Escalation**: The injected malware inherits the **same rights and permissions** as the legitimate target process. If the target process runs with elevated privileges (e.g., as a system service or Administrator), the malware will automatically gain those same high privileges, allowing it to perform actions it normally couldn't.

## DLL Injection (A Common Memory Injection Method)

### Definition of DLL
- **Dynamic-Link Library (DLL)**: A type of Windows library file containing code and data that can be used by multiple programs simultaneously.
- DLLs are essential components that applications can load and call upon to perform specific functions.

### How DLL Injection Works
DLL injection is one of the most popular and relatively easy-to-implement memory injection methods:
1. **Malicious DLL Placement**: The attacker first needs to get their malicious DLL file onto some storage location on the target system that the system can access (e.g., a specific folder on the hard drive).
2. **Path Injection**: The attacker then uses a separate piece of code (often a small loader) to inject a **path** (the location of the malicious DLL on disk) into the memory space of a legitimate, running target process.
3. **Legitimate Process Loads Malicious DLL**: As the target process continues to execute its normal code, it eventually reaches the injected path. Because this path now appears as part of its own memory space, the legitimate process, following its normal operational procedures, attempts to load the DLL specified by that path.
4. **Execution**: The malicious DLL is loaded from disk into the target process's memory space and begins to execute. From the operating system's perspective, this malicious code is now simply part of the legitimate process, making it difficult to distinguish from normal activity.

## Takeaways for Exam
- **Malware must reside and execute in memory**. Understanding memory operations is critical for cybersecurity.
- **Memory forensics** is the technique used to analyze live or captured memory for signs of malicious activity.
- **Memory Injection Definition**: It's the act of inserting malicious code into the memory space of an *already running, legitimate process*.
- **Primary Goals of Memory Injection for Attackers**:
    1. **Evasion**: To bypass traditional security software that monitors for new, suspicious *processes*.
    2. **Privilege Escalation**: To inherit the rights and permissions of the legitimate process, potentially gaining higher access than the malware would normally have.
- **DLL Injection as a Specific Method**: Know that a Dynamic-Link Library (DLL) is a common component used in this type of attack, especially on Windows systems.
- **Mechanism of DLL Injection (Key Steps)**:
    1. Malicious DLL is secretly placed on the victim's disk.
    2. A *path* to this malicious DLL is injected into the memory of a legitimate target process.
    3. The legitimate process, while executing, encounters this injected path and *loads the malicious DLL* into its own memory, believing it's a legitimate component.
    4. The malicious DLL then executes within the context and privileges of the legitimate process.
- **Impact**: Memory injection makes malware harder to detect by traditional means and allows it to operate with elevated privileges, blending in with normal system operations.
