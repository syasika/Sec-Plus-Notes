# Firewall Types

## Introduction to Firewalls

**Definition**: A universal security control essential for managing internet connectivity in homes, offices, and even operating systems. Firewalls are crucial for controlling the flow of network traffic between two points.

- **Core Function**: Manage inbound and outbound data for networks (e.g., corporate environments with sensitive materials), block inappropriate content ("not safe for work" sites, parental controls), and protect against malicious software (integration with antivirus/anti-malware).
- **Principle**: Everything passes through the firewall, allowing for inspection and control.

### Network-based Firewalls

**Definition**: A purpose-built appliance that filters network traffic.

- **Filtering Capabilities**:
  - **Traditional Firewalls**: Filter traffic based on **OSI Layer 4 (Transport Layer)** using TCP/UDP port numbers (e.g., allowing HTTP traffic on port 80 but blocking SSH traffic on port 22).
  - **Next-Generation Firewalls (NGFWs)**: Filter traffic based on **OSI Layer 7 (Application Layer)**, allowing or disallowing traffic based on the application itself.

#### Additional Functionality:
- **Encrypt Traffic**: Can integrate Virtual Private Network (VPN) services for secure site-to-site communication.
- **Layer 3 Devices (Routers)**: Many firewalls also operate as routers and can be placed at ingress/egress points of the network to control traffic flow between internal and external networks. They provide **Network Address Translation (NAT)** functionality.

## Unified Threat Management (UTM) / All-in-one Security Appliance

**Definition**: Older devices that bundle multiple security features into a single appliance, including URL filter/content inspection, malware inspection, spam filter, CSU/DSU for WAN connectivity, router and switch functions, firewall, IDS/IPS, bandwidth shaper, and VPN endpoint.

### Key Features:
- **URL Filter / Content Inspection**: Allows/disallows access to specific websites or content.
- **Malware Inspection**: Identifies and blocks malware.
- **Spam Filter**: Blocks unwanted email correspondence.
- **CSU/DSU (Channel Service Unit/Data Service Unit)**: Provides WAN connectivity services.
- **Router, Switch**: Basic networking functions.
- **Firewall**: Basic packet filtering capabilities.
- **IDS/IPS**: Intrusion Detection System/Intrusion Prevention System for blocking malicious software.
- **Bandwidth Shaper (QoS)**: Prioritizes traffic.
- **VPN Endpoint**: Secure remote access.

### Challenge: Many UTMs primarily operate at **OSI Layer 4**. Bundling multiple security capabilities on a single appliance can lead to performance drawbacks and slow down the device.

## Next-Generation Firewall (NGFW)

**Definition**: A modern type of firewall that operates at **OSI Application Layer (Layer 7)**, inspecting all data in every packet for comprehensive security.

### Key Capabilities:
- **Deep Packet Inspection (DPI)**: Analyzes every piece of data in each packet.
- **Application Control**: Granular control over specific applications.
- **Integrated IPS**: Applies vulnerability signatures to block known exploits.
- **Content Filtering**: Uses URL filters to control website traffic by category and specific URLs.

### Operation:
- **Advanced Decodes**: Every packet is analyzed and categorized before a security decision is made.
- **Forwarding Decisions Based on Application**: Recognizes who is sending traffic, where it's going, and what's contained within the application layer.

### Functionality Examples:
- **Control Traffic Based on Application**: E.g., allow Microsoft SQL Server traffic regardless of port, allow viewing Twitter but not posting, restrict YouTube videos.
- **Intrusion Prevention Systems (IPS)**: Identifies applications and applies application-specific vulnerability signatures to block known exploits.
- **Content Filtering**: Uses URL filters to control website traffic by category or specific URLs.

## Web Application Firewall (WAF)

**Definition**: A specialized firewall designed to protect web applications.

### Distinction from "Normal" Firewalls:
- **Focus**: Applies rules specifically to **HTTP/HTTPS conversations** and protects against web application-specific attacks.

#### Mechanism:
- Allows or denies traffic based on expected input for web applications.
- Unexpected input is a common method for exploiting web applications.

#### Protection Against:
- **SQL Injection**: Blocks attempts to add malicious commands to an application's SQL query.
- Cross-site scripting (XSS).
- Web-based errors.

### Compliance: A major focus of the Payment Card Industry Data Security Standard (PCI DSS), especially for applications handling credit card data.

### Deployment: Often used alongside NGFWs, with each focusing on different aspects of traffic and making different forwarding decisions.

### Log Example:
- Shows blocked attacks like "SQL Injection in Parameter" and "Cross-Site Scripting in JSON Data," indicating the WAF's ability to analyze specific web application attack patterns.

# Exam Takeaways

1. **Firewall's Core Role**: Firewalls manage network traffic flow (inbound/outbound, content, malware protection). Everything goes through them.
2. **OSI Layer Distinction is Key**:
   - **Traditional Firewalls**: Operate at **Layer 4**, filtering based on port numbers (TCP/UDP).
   - **Next-Generation Firewalls (NGFWs)**: Operate at **Layer 7**, filtering based on the application itself (e.g., blocking Twitter posts while allowing viewing).

3. **NGFW Capabilities**: Be aware of NGFWs' advanced features:
   - **Deep Packet Inspection (DPI)**: Analyzes all data in every packet.
   - **Application Control**: Granular control over specific applications.
   - **Integrated IPS**: Applies vulnerability signatures.
   - **Content Filtering**: URL categories and specific URLs.

4. **UTM: The "All-in-One" Trade-off**:
   - **Purpose**: Bundles multiple security functions (firewall, router, switch, IDS/IPS, malware, spam, URL filtering, VPN) into one device.
   - **Limitation**: Often operates at Layer 4 for many features. Bundling too many features can lead to performance bottlenecks.

5. **WAF: The Web Application Specialist**:
   - **Unique Role**: A WAF focuses specifically on HTTP/HTTPS conversations and guards against web application-specific attacks by analyzing expected input.
   - **Protection**: Guards against SQL injection, cross-site scripting, and web-based errors.
   - **Regulatory Importance**: Critical for compliance standards like PCI DSS.
   - **Deployment**: Often works alongside NGFWs for comprehensive protection.

6. **Know the Names**:
   - UTM = Web security gateway, All-in-one security appliance.
   - NGFW = Application layer gateway, Stateful multilayer inspection, Deep packet inspection.

7. **Performance Considerations**: Advanced inspection (Layer 7, Deep Packet Inspection, multiple UTM features) requires more processing power and can impact network performance.
