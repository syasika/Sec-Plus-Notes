# Security Standards

## Overview
- **Definition**: A formal definition for using security technologies and processes. It provides clear guidelines for handling different situations, reducing security risks, and ensuring everyone understands expectations.

## Password Standards
### Purpose
- Define what constitutes a "good password" within an organization.
- Crucial to create a formal **password complexity policy** to ensure strong security practices.

### Key Aspects of Password Standards:
- **Password Complexity Policy**: Defines requirements such as minimum length, character types (uppercase, lowercase, numbers, symbols), and exclusion of common words or personal information.
- **Acceptable Authentication Methods**: Specifies how users authenticate (e.g., no local accounts, only LDAP to Active Directory database) for secure and centralized authentication.
- **Secure Password Resets**: Policies to prevent unauthorized resets and ensure proper identity verification during the reset process.
- **Other Password Policies**:
  - **Password Change Frequency**: How often passwords must be changed.
  - **Secure Password Storage Requirements**: Methods like hashing (e.g., salted hashes) instead of plain text storage.
  - **Password Manager Options**: Approved password managers for users.

## Access Control Standards
### Purpose
- Determine who can access which information, at what time, and under what circumstances.

### Key Aspects of Access Control Standards:
- **Define Access Control Types**: Specify allowed/disallowed models (e.g., no discretionary access control, only mandatory access control).
- **Determine How Users Get Access**: Requires privilege documentation (e.g., management sign-off, completion of training courses) to ensure access is granted based on the principle of least privilege and separation of duties.
- **Document How Access May Be Removed**: Policies for revoking access due to security issues, account expiration, contract renewals, or employee termination.

## Physical Security Standards
### Purpose
- Rules and policies regarding physical security controls, covering doors, building access, and general property security.

### Key Aspects of Physical Security Standards:
- **Granting Physical Access**: Different procedures for employees vs. visitors (e.g., ID badges, electronic door locks) with mandatory escorts for visitors.
- **Define Specific Physical Security Systems**: Types of electronic door locks (e.g., biometric integration), ongoing monitoring requirements (e.g., CCTV, security personnel), and motion detection systems.
- **Additional Security Concerns**:
  - Mandatory escorts for visitors.
  - Off-boarding procedures for physical access (e.g., badge retrieval).

## Encryption Standards
### Purpose
- Define specific standards for encrypting and securing data.

### Key Aspects of Encryption Standards:
- **Password Storage**: Specify methods and techniques like hashing, salted hashing, and exact algorithms to be used.
- **Data Encryption Minimums**:
  - Define required algorithms for different states of data (data in use, data in transit, data at rest).
  - Higher encryption requirements may apply to data in transit over public networks.

## Takeaways for Exam
1. **Core Concept**: Security standards are formal, documented definitions for security technologies and processes, essential for reducing risk and ensuring consistent security practices.
2. **Types of Standards**:
   - **Password Standards**: Complexity, authentication methods, reset procedures, storage.
   - **Access Control Standards**: Data access determination (who, what, when, how), access types (discretionary vs. mandatory), and access removal.
   - **Physical Security Standards**: Building access, employee vs. visitor protocols, specific security systems (locks, monitoring), and off-boarding.
   - **Encryption Standards**: Cryptographic methods, password storage, and data encryption minimums for different states of data.
3. **In-house vs. Industry Standards**: Organizations can develop their own standards or adopt existing industry standards like ISO or NIST.
4. **Password Policy Details**: Key elements include complexity (length, character types), acceptable authentication methods (e.g., LDAP, no local accounts), and secure reset procedures.
5. **Access Control Principles**: Access control standards define how users get access and how that access is revoked.
6. **Physical Security Scope**: Physical security covers not just doors and locks but also monitoring, visitor management, and specific hardware.
7. **Encryption States**: Different encryption requirements based on the state of data (data in use, data in transit, data at rest).
8. **Documentation**: Complete documentation is vital for all security standards to ensure clarity and consistency.
9. **Connection to Risk**: All these standards aim to reduce security risk by establishing clear, consistent, and robust security measures.
