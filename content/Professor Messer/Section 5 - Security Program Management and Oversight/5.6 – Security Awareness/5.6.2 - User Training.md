# User Training: Security Awareness & Guidance

## Overview
- **Definition**: Ensuring that users are trained to protect data resources from unauthorized access, attacks, theft, and damage.

---

## 1. Security Awareness Training

### Importance
- **Best Practice**: Train users before they gain network access.
- **Purpose**: Ensure detailed understanding of security requirements.

### Key Aspects
- **Specialized Training**:
    - Each user role has unique security responsibilities.
    - Example: Accounting department requires different security measures than shipping/receiving.
    - Tailor training to specific roles.
- **Third-Parties**:
    - Training extends to external entities connecting to the network.
    - Includes contractors, partners, and suppliers.
    - Crucial for protecting devices and services from outside connections.
- **Documentation & Records**:
    - Maintain detailed records of trained users.
    - Reason: Untrained users can cause severe problems.

---

## 2. User Guidance and Training

### Policy/Handbooks
- **Documentation**: All security requirements must be documented.
- **Accessibility**:
    - Provide online access (e.g., on an intranet).
    - Reference policies in the employee handbook.
    - Ensure easy reference for all users.

### Situational Awareness
- **Constant Vigilance**: Users should always look for threats, regardless of their job function.
- **Software Attacks**:
    - **Email Links**: Phishing attempts.
    - **Attachments**: Malicious files.
    - **Unusual URLs**: Suspicious websites.
    - **Text Messages**: Smishing attempts.
- **Physical Attacks**:
    - **USB Drives**: Found in unexpected places (e.g., FedEx envelope). Do NOT plug unknown USB drives into your computer.
    - **Unlocked Building Doors**: Tailgating, unauthorized access.
- **Overall**: Be ready for anything and question unusual occurrences.

### Insider Threat
- **Challenge**: Difficult to guard against because insiders already have legitimate access.
- **Users as Protectors/Threats**: Employees can be both the strongest defense or the weakest link.
- **Mitigation Strategies**:
    - **Multiple Approvals**: Require more than one person's approval for critical processes.
    - **Monitoring**: Actively monitor files and systems for unauthorized changes. Receive immediate alerts.
    - **Difficulty of Change**: Make it very difficult to make unauthorized changes or circumvent security systems.

### Password Management
- **Standards**: Many standards exist for secure passwords (e.g., length, complexity).
- **Guidance**: Guide users with clear, standard requirements.
- **Enforcement**: Often controlled using technology like Group Policy in Windows environments to enforce password rules.

### Removable Media and Cables
- **Security Risk**: Both can be sources of security concerns.
- **Unknown USB Drives**: Can contain malware. Users should never plug unknown USB drives into their computers.
- **Unknown Cables**: Can be malicious. Avoid using random cables for charging or data transfer, especially in public places.

### Social Engineering
- **Effectiveness**: Attackers are highly skilled at social engineering.
- **Training**: Requires extensive and ongoing training.
- **User Role**: Users are the organization's first line of defense.
- **Response**:
    1. Identify social engineering attempts.
    2. Understand the nature of the attack.
    3. Report it to the IT security team.

### Operational Security
- **Perspective**: Users should view security from the attacker's perspective.
- **Sensitive Data**: Users need to:
    1. Identify what data is sensitive.
    2. Understand how to keep sensitive data private and secure.

### Hybrid/Remote Work Environments
- **Increased Risks**: Working from home or remote sites introduces new security risks.
- **Access Control**:
    - No access for family and friends to work systems/devices.
    - Maintain strict separation between personal and work use.
- **Endpoint Security**: Implement additional endpoint security on remote devices (since they are outside the physical building's perimeter).
- **VPN Access**: Strict security policies for VPN access. Ensure secure connection and authentication when connecting from home or other locations.

---

## Takeaways

1. **Security Training is Foundational**: Training is a non-negotiable best practice, ideally conducted before network access. It's not a one-time event but requires continuous effort.
2. **Tailored Training**: Recognize that "one size does not fit all." Security training must be specialized based on user roles and extend to third-parties.
3. **Documentation is Key**: Keeping detailed records of training is crucial for compliance, accountability, and identifying training gaps. Policies should be well-documented and easily accessible.
4. **Situational Awareness: The Human Firewall**: Users are the first line of defense. They need to be trained to actively look for threats, both software-based (phishing links, malicious attachments, unusual URLs/texts) and physical (unknown USBs, unlocked doors, tailgating).
5. **Insider Threats Are Complex**: These are hard to detect because they leverage legitimate access. Mitigate with multiple approvals for critical processes, active monitoring of files/systems, and making unauthorized changes extremely difficult.
6. **Strong Password Management**: Users need guidance on creating secure passwords (length, complexity). Technology like Group Policy can enforce these standards administratively.
7. **Removable Media & Cables Are Threat Vectors**: Emphasize the danger of unknown USB drives (malware) and malicious cables. Users should be highly suspicious of any unsolicited physical media.
8. **Social Engineering: The Persistent Threat**: Attackers are sophisticated. Training must be extensive and ongoing to equip users to identify, understand, and report social engineering attempts effectively. Users are the "front-line defense" against these attacks.
9. **Operational Security Mindset**: Encourage users to think like an attacker to better protect sensitive data. They must be able to identify sensitive information and understand its privacy requirements.
10. **Remote Work's Unique Challenges**: Hybrid/remote work introduces new risks. Key controls include strict policies against family/friends accessing work systems, enhanced endpoint security on remote devices, and robust VPN security policies for remote access.
